# Atividade Prática - HTML Semântico e Acessibilidade Web

Repositório criado para a entrega da atividade prática da disciplina de **LIMA (Linguagem de Marcação)**, focada na estruturação de páginas web com HTML5 puro, aplicando boas práticas semânticas e diretrizes de acessibilidade.

---

## 🎯 Objetivo da Atividade

Aplicar, na prática, os conceitos de linguagens de marcação por meio da construção de uma página HTML semântica e acessível baseada em um modelo institucional. A atividade busca consolidar a compreensão sobre o uso correto das tags estruturais, a hierarquia de títulos e a importância do HTML limpo para leitores de tela e motores de busca.

---

## 📄 Conteúdo da Página (`index.html`)

O arquivo principal da atividade consiste em uma página pessoal/profissional contendo:

* **Cabeçalho (`<header>`):** Apresentação inicial do nome e da área de atuação principal.
* **Seção "Sobre mim" (`<section>`):** Texto descritivo sobre a trajetória acadêmica no SESI/SENAI, a atuação como desenvolvedora de sistemas e as metas de futuro na área de Direito Criminal com análise de dados.
* **Seção "Hobbies" (`<section>`):** Lista não ordenada (`<ul>`) detalhando as atividades cotidianas de lazer.
* **Rodapé (`<footer>`):** Informações de direitos autorais e *copywriting*.
* **Reflexão Técnica:** Comentário direto no código fonte explicando o impacto das escolhas semânticas na acessibilidade web e a substituição de tags obsoletas (como a remoção da tag `<center>`).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica sem o uso de estilizações inline ou tags depreciadas.
